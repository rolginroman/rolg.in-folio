# Font used by the Ledger demo

`recursive-latin-MONO-wght.woff2` — **Recursive Variable**, latin subset, carrying
two axes: `MONO` (0 = proportional sans, 1 = monospace) and `wght` (300–1000).

Recursive by ArrowType (Stephen Nixon), licensed under the
SIL Open Font License, Version 1.1 — <https://openfontlicense.org>.
Source: <https://github.com/arrowtype/recursive>.

Copyright 2019 The Recursive Project Authors (github.com/arrowtype/recursive)

Self-hosted on purpose: the page makes no request to a font CDN. The file is the
`latin` + `MONO` cut as published in `@fontsource-variable/recursive@5.3.0`,
downloaded once and committed here. One file serves both typographic voices —
the text face and the metadata face are the same design at two positions on its
`MONO` axis — so this world ships a single font request, not two.
